# 🏥 Hospital Database Analysis Using SQL

## 📌 Project Overview
This project uses SQL to analyze hospital data, including patients, doctors, admissions, diagnoses, and patient demographics. It demonstrates how SQL queries can retrieve, filter, and summarize healthcare data.

## 🎯 Objectives
- Retrieve and filter patient records.
- Analyze patient demographics and allergies.
- Explore hospital admissions and diagnoses.
- Calculate patient counts and aggregate statistics.
- Join multiple tables to extract meaningful information.

## 🛠️ Tools & Technologies
- **MySQL**
- **SQL Queries**
- **Aggregate Functions**
- **Joins and Subqueries**
- **GROUP BY and ORDER BY**
- **CASE Statements**

## 📂 Project File
- `Doctor_sql.sql` — Database creation, table definitions, and SQL queries for hospital data analysis.

## 📚 Key SQL Concepts
SELECT, WHERE, JOIN, GROUP BY, HAVING, ORDER BY, COUNT, AVG, MAX, MIN, UPDATE, and subqueries.

## ✅ Conclusion
This project demonstrates practical SQL skills for querying and analyzing hospital data, with a focus on patient information, admissions, and healthcare statistics.
